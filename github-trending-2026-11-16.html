一、为什么找不到「右上角三个筛选」

  • 先确认地址：推荐卡片流是 github.com/explore，那里本来就没有时间 / 语言筛选；带筛选的榜单在 github.com/trending。
  • Trending 顶部那一行工具栏是 JS 异步加载的。好助理抓静态页时只拿到仓库列表，完全没有 Date range / Language 的控件文字 —— 国内网络下这块很容易空白或一直 Loading。
  • GitHub 改版多次：语言选择常在左侧或中部，Date range 在右上，窄屏还会折叠进下拉。「右上角三个」这个说法不够准，好助理更正。

最省事的解法：别找 UI，直接拼 URL。下列参数已实测生效 —— /trending/python?since=weekly&spoken_language_code=zh 返回的就是「Python · 本周 · 中文」榜。

参数规则：时间 ?since=daily|weekly|monthly；编程语言走路径 /trending/typescript；README 语言 &spoken_language_code=zh。想看 AI Agent 扎堆的 TypeScript 周榜：https://github.com/trending/typescript?since=weekly
